📈 ARIMA Model for Time Series Forecasting
This repository contains a Jupyter Notebook implementing the ARIMA (AutoRegressive Integrated Moving Average) model for time series forecasting. It includes:

Exploratory data analysis (EDA)

Seasonal decomposition

ARIMA modeling using pmdarima.auto_arima

Model evaluation with RMSE and MSE

Forecast visualization

The dataset used is included in the dataset/ folder and represents monthly airline passenger data.
